# Rights and licensing scope

This package preserves author-generated experiment outputs and research scripts for scholarly inspection. No new software license is asserted here pending explicit confirmation of the copyright owner's chosen license. Third-party datasets, upstream code, model weights, and external software retain their own terms; they are not relicensed by this package. The `code/` directories reproduce scientific implementations from the research materials, whereas research benchmark text and model weights must be obtained from original providers.
